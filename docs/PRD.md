# PRD — Poker EV Calculator

## 一句话

用三个可观测的输入（手牌强度、对手类型、对手动作）估出胜率，把弃牌/跟注/加注的期望收益摆在一起比，并告诉你"至少多强才该跟"。

## 要解决的问题

打牌时的每个决策都是期望值计算，但现有工具分两极：

- **Solver 类**（PioSOLVER、GTO+）：精确，但要输入完整对手范围，学习成本高，算一手要几分钟
- **底池赔率计算器**：三秒算完，但只回答"需要多少胜率"，不管对手是谁、他刚做了什么

中间这段是空的：我知道对手打得紧、他刚加注了、我手里 99 —— 我该跟吗？

## 目标用户

- 打微额到中额线上/线下现金局的玩家，想做直觉校准
- 想理解 EV 决策框架的人（工具本身是教具）

明确不服务：需要精确 solver 输出去指导真钱决策的严肃玩家。见 README 的局限章节。

## 核心场景

1. **牌局复盘**：昨天那手 99 面对紧对手加注，我弃了，对不对？→ 填参数，看三个 EV
2. **参数不确定时的稳健性检查**：我估手牌强度 60，但可能高估了 —— 到多少会翻盘？→ 敏感性分析给出临界值
3. **学习**：翻 8 个经典案例，看"为什么听牌该跟不该加"

## 功能范围

### P0（已实现）

| 功能 | 说明 |
|---|---|
| 参数输入 | 手牌（两张牌选择器）、公共牌、底池、我方/对手筹码、对手类型、对手动作与金额 |
| 三决策 EV 对比 | 柱状图并排，最优决策高亮 + 一句话理由 |
| 关键指标 | 估算胜率、底池赔率、需要胜率、对手弃牌率、被跟注后胜率 |
| 敏感性分析 | 手牌强度 0→100 扫描，三条 EV 曲线 + 临界强度（跟注转正点、加注超过跟注点） |
| 8 个经典案例 | 一键填充，展示预期决策与实际计算是否一致 |
| 假设透明 | 关于 tab 列出全部修正常数，数值从 `lib/ev.ts` 读取而非手写 |

### 不做（P-）

- 多人底池（只支持单挑）
- 多条街联合优化 / 隐含赔率
- 加注尺度优化（固定 3 倍）
- 对手范围输入
- 牌局历史导入 / 手牌记录
- 抽水
- 账号、云端保存

3. README 表格里的每个数字都能在 `results/cases.json` 里找到（脚本比对）
4. `results/cases.json` 已提交，且与实时计算一致（CI 断言）
5. GitHub Pages 可访问，四个 tab 都能正常交互

## 关键设计取舍

写在 `docs/DECISIONS.md`。最重要的一条：加注 EV 用"被跟注后胜率"而不是整体胜率，
这是偏离任务书字面公式的唯一处，也是 8/8 命中的前提。

## 假设

写在 `docs/ASSUMPTIONS.md`。所有凭空取值的常数都在那里，标了来源和敏感度。

## 技术选型

- Next.js 15 App Router + 静态导出 → GitHub Pages 零成本托管
- 全部计算在浏览器本地，无后端 → 无隐私问题、无运维
- Chart.js → 两种图（柱状 + 折线）够用，比 D3 轻
- CSS Modules → 任务书要求，且样式量小
