## 视觉复核

使用 app-screen 路线，方向 achromatic-ledger，seed 1641742422。桌面与手机的首屏和全页截图均已人工查看。检查器最后一轮为 0 FAIL / 2 WARN；随后补齐全局等宽数字。牌面花色为实际输入数据，允许 suit 字符，不是装饰 emoji。

七点设计判断：

1. 主任务：输入假设、比较收益、检查切换、保存比较；页面没有另起营销首屏。
2. 信息层级：输入与结果桌面并列；手机单列，参数组和结果组各自连续。
3. 数据表达：行动编码固定为灰 / 蓝 / 墨色；线图不平滑伪造采样点，结论不只靠颜色。
4. 密度：保留原有四工作区。数字和解释有层次，不强行把模型边界塞入 tooltip。
5. 控制与恢复：默认、草稿、导出、禁用状态有明确反馈；牌面可键盘修改。
6. 视觉一致性：中性工作台，无背景光晕或渐变；不引入另一套组件框架。
7. 剩余取舍：两列分别服务输入与输出，内容长度不同，保留自然结束位置，不用空白把两列卡片伪装成等高。误差范围仅覆盖强度，不声称完整鲁棒性验证。
