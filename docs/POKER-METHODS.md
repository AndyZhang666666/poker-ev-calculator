# Poker Lab 的计算与训练口径

## 摊牌权益

输入为 Hero 两张牌、0/3/4/5 张公共牌，以及对手确定的两张牌或加权手牌范围。只计算一个对手。重复牌、非法阶段、空范围、被已知牌完全排除的范围均拒绝计算。

范围支持对子、同花 s、非同花 o、加号、同高张区间和同间隔连张区间。例如 TT+、A5s-A2s、T9s-54s。AK 表示 AKs 和 AKo。权重可用 0–1 或百分比，重复项以后写的为准。保存与参考快照保留频率精度，不将小权重静默归零。

对子原始组合为 6，同花为 4，非同花为 12。移除已知牌后，再按剩余组合的权重归一化。某个类别的权重施加在它的每个可用物理组合上。

权益 = P(获胜) + P(平局)/2。确定的结果可以达到 0% 或 100%，不沿用旧 EV 模型的 5%–95% 截断。

当所有合法对手组合 × 合法发牌路径不超过 200,000 个局面时，自动精确枚举。其余按给定种子抽样：先按权重选择对手组合，再从余牌中无放回补全公共牌。抽样上限 200,000 次，运行在独立 worker；停止会终止本组计算。

抽样结果采用有界收益的 Hoeffding 区间：半宽为 sqrt(log(40)/(2n))，截到 [0,1]。它是模型下的保守 95% 抽样界，不能覆盖对手范围假设、行为变化或其他模型缺失。精确枚举没有抽样区间。耗时仅为本次设备上的计算耗时，不是跨设备性能承诺。

结果保存完整输入、模型版本、种子和统计。改变输入后旧结果保留并标明其归属，重新计算完成前不能导出为新结果。没有加入未来下注、弃牌收益、抽水或多人边池，也没有用权益直接判定完整策略最优。

## 开池训练

内置参考：六人现金桌、100bb、无前注，前面所有玩家均弃牌，只练加注或弃牌。位置包括 UTG、HJ、CO、BTN、SB。BB 在前面均弃牌时直接收盲，不作为开池题。

五个位置范围是可修改的教学参考。小盲同样采用简化的加注/弃牌口径，不声称它覆盖平跟策略。基础 30 手用于熟悉边界；随机题从 1,326 个真实两张牌组合抽样，不把 169 个类别误当成等概率。

频率为 0 时只接受弃牌，为 1 时只接受加注；介于 0 和 1 之间时两种动作均被接受并显示参考频率。单次动作不检验长期随机化频率，也不生成未经求解的 EV 损失评分。

每组开始时固定参考快照。中途修改编辑器从下一组生效。题目与错题保留完整参考文字、参考指纹、具体两张牌、位置和说明；修改当前参考不回写旧题。

## 错题与保存

按位置、手牌类别和参考指纹合并同类错题。偏离参考会进入待重练；连续两次重练符合当时的参考后标记已巩固。再次偏离会重新打开。手动归档可恢复，作答统计仍按保留的原始作答计算。

本机保留最近 500 次作答、最多 200 个错题条目和当前参考范围。导入校验卡牌、参考、动作、时间、条目上限等字段；相同作答 ID 不重复计数。可选择是否同时载入备份里的参考范围。备份上限为 8 MB，覆盖本工具的保留规模。

浏览器禁用存储、额度不足或记录损坏时显示提示，当前会话仍可练习并导出。损坏记录不会被当成有效进度；重新启用保存需由用户点击对应控件。无账号、云同步或跨站自动共享。清理网站数据会移除本机记录。

## 原 EV 沙盘

四个旧工作区仍由原代码管理，旧 hash 可直接访问。其强度评分、弃牌率和单轮模型仍保留原限制；公共牌只作记录。真实算牌与旧 EV 模型分开展示，不能把新引擎的权益结果误当成旧模型已完成校准。
